# Лавка Странника — Telegram-магазин нейросетей

Бот на aiogram 3, мини-приложение и защищённая админка на aiohttp + SQLite. Две стартовые категории: ChatGPT и Gemini. Реальные товары, цены и остатки добавляет владелец; демо-покупок и выдуманного баланса нет.

## Предзаказ, автовыдача и тестовые товары

- **Предзаказ по предоплате 100%.** Если обычного товара нет в наличии, кнопка в карточке автоматически становится предзаказом (в чате и мини-лавке). Предзаказы пользователя также видны ему в кнопке «⏳ Предзаказы». Когда товар поступает, бот **сначала выдаёт оплаченные предзаказы по очереди оформления** и отправляет товар покупателю в чат; только остаток выставляется на полку.
- **Автовыдача.** В карточке товара у администратора есть кнопка «📤 Загрузить автовыдачу»: бот просит отправить список, где **одна строка = одна единица товара** (логин:пароль, ключ, ссылка; до 200 строк по 2000 символов). После загрузки бот сразу гасит очередь оплаченных предзаказов, остаток идёт на полку, а при отметке оплаты любого заказа строки уходят покупателю автоматически сообщением в чат.
- **Тестовые товары.** В админке у товара есть флажок «Тестовый товар». Такие товары видят только владелец и тестеры (переменная окружения `TESTER_IDS` — Telegram ID через запятую; админы тоже могут тестировать). Тестер жмёт «🧪 Тестовая покупка без оплаты» в чате или мини-лавке — заказ создаётся сразу со статусом «Выдан», деньги не списываются, в статистику профиля покупка не попадает, а бот мгновенно отправляет строку товара в чат. Так проверяется автовыдача до реальных продаж.

## Меню бота

- `/menu` и `/start`: фотография `webapp/1.jpg`, благодарность и четыре синие кнопки: «🛒 Товары», «👤 Профиль», «💰 Кошелёк», «🛟 Техподдержка».
- «Товары»: `webapp/shop.jpg`, приветствие в магической лавке нейросетей, кнопки ChatGPT и Gemini, а также кнопка «⏳ Предзаказы» — отдельная полка со всеми товарами, которые можно заказать с предоплатой 100%. При настроенном `WEBAPP_URL` категории открывают нужную категорию мини-приложения; без него бот показывает список прямо в чате.
- Цвета кнопок в чате: кнопка товара горит <b>зелёным</b>, если товар в наличии, и <b>красным</b>, если закончился; «Купить» и «🧪 Тестовая покупка» — зелёные; «Назад» и «Отмена» — красные; кнопка предзаказа — без цвета (это не покупка, а заявка на поступление).
- «Профиль»: `webapp/2.jpg`, число купленных единиц товара, потраченная сумма, порядковый номер пользователя и любимый товар. Учитываются только заказы со статусом `paid` или `done`.
- «Кошелёк»: реальный сохранённый баланс (изначально 0); пополнение и автоматическая оплата пока не подключены.
- «Техподдержка»: ссылка на пользователя из `SUPPORT_USERNAME` (по умолчанию `DitzzmBack`).
- Синий цвет задаётся официальным полем Telegram `style="primary"`. Старые клиенты могут отображать кнопки стандартно. Логотипы внутри кнопок не подменяются похожими эмодзи: категории оставлены текстовыми.

## Как получить админку

1. Напиши своему боту `/id` или `/admin`. Он покажет **твой числовой Telegram ID**.
2. На хостинге приложения открой переменные окружения и добавь `ADMIN_IDS` со значением этого ID. Для нескольких администраторов — ID через запятую.
3. Укажи в `WEBAPP_URL` публичный **HTTPS-адрес запущенного приложения**, не ссылку на GitHub-репозиторий или GitHub Pages.
4. Перезапусти / повторно разверни приложение.
5. Напиши `/admin` и нажми «Открыть админку» внутри Telegram.

Нет отдельного пароля и нет назначения администратора первому посетителю. Сервер проверяет подпись Telegram и сравнивает ID с `ADMIN_IDS`; изменение URL или клиентского кода не даёт прав администратора.

В панели доступны категории, товары, цены, остатки и заказы. Предзаказ включается автоматически для обычного товара с нулевым остатком. Чтобы начать продажи: добавь товар, укажи цену в целых рублях, остаток и загрузи автовыдачу кнопкой в карточке товара в чате. «Оплачен» нажимай только после реального получения оплаты — бот сразу попробует выдать товар автоматически. Оформление заявки само по себе не означает оплату. Отмена обычной неоплаченной заявки возвращает остаток один раз; предзаказ остаток не резервирует и действует по предоплате 100%.

Быстрое добавление товара из чата — команда `/add` (только для владельца): бот сразу спрашивает категорию полки, затем тип товара (кнопки «🧪 Тестовый товар» / «📦 Обычный товар»), после чего название, цену, остаток и описание. «Отмена» в мастере — красная; отмена на любом шаге — `/cancel`.

## Установка и запуск

Нужен Python 3.10 или новее.

```sh
python -m venv .venv
# Активируй окружение: Windows — .venv\Scripts\activate; Linux/macOS — source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Перед запуском задай переменные окружения в терминале или панели хостинга. Файл `.env` автоматически не читается.

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Секретный токен от BotFather. Только в окружении хостинга, не в GitHub |
| `WEBAPP_URL` | Публичный HTTPS-адрес этого Python-приложения |
| `ADMIN_IDS` | Числовые Telegram ID владельцев, через запятую |
| `TESTER_IDS` | Telegram ID тестеров через запятую: им видны тестовые товары и доступна тест-покупка без оплаты |
| `SUPPORT_USERNAME` | Telegram username поддержки без `@`; по умолчанию `DitzzmBack` |
| `DB_PATH` | Путь к SQLite на постоянном диске; по умолчанию `shop.db` рядом с `app.py` |
| `HOST` | По умолчанию `0.0.0.0`, чтобы контейнерный хостинг мог принять внешний трафик |
| `PORT` | Порт хостинга; по умолчанию `8080` |
| `WEB_ONLY` | `1` для локального просмотра каталога без запуска бота; не для рабочего бота |

## GitHub и хостинг — разные шаги

Публикация исходников в GitHub **не запускает бота**. На хостинге выбери этот репозиторий, команду установки `python -m pip install -r requirements.txt`, команду запуска `python app.py`, задай окружение и перезапусти сервис. После получения домена запиши его в `WEBAPP_URL`.

Запускай только один polling-процесс на один токен. Если ранее был настроен webhook, сначала отключи его в настройке существующей интеграции. SQLite должен находиться на постоянном диске: на временной файловой системе при новом развёртывании можно потерять пользователей, остатки и заказы. Перед переносом сделай резервную копию базы. Миграция сохраняет старые товары и заказы; старые демо-категории скрываются из публичного каталога без удаления записей.

Ошибки 404 на `/api/catalog`, `/api/config`, `/api/me` означают, что открыт статический сайт, запущена старая версия сервера или неверно настроен прокси. Обновлённый `app.py` обслуживает HTML, `/static/` и `/api/` с одного домена. Нижняя навигационная панель убрана; профиль, кошелёк и поддержка открываются в боте.

## Проверка

```sh
python -m unittest discover -p "test_*.py" -v
```

`GET /health` возвращает `{"ok": true}`. Публичные API: `/api/catalog`, `/api/products`, `/api/config`. `/api/me`, создание заказа и `/api/admin/*` требуют подписанного Telegram `initData` в заголовке `Authorization: tma ...`. Подпись имеет ограниченный срок действия. Заказы защищены от дублирования при повторе запроса.

## Файлы

- `app.py` — Telegram-бот, фотографии, кнопки и запуск HTTP-сервера.
- `shop_backend.py` — база данных, авторизация, API каталога и управления.
- `webapp/index.html` — мини-приложение с каталогом и админкой без нижней панели.
- `webapp/1.jpg`, `webapp/shop.jpg`, `webapp/2.jpg` — предоставленные фотографии сообщений.
- `test_shop.py` — автоматические проверки.
- `shop.db` — рабочая база; не коммитится.
